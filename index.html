02 · Android Nativo · Seguridad Personal

GuardIA

Aplicación de seguridad personal con persistencia local offline-first, sincronización en la nube y detección inteligente mediante sensores del dispositivo.

  • Arquitectura limpia desarrollada en Kotlin y Jetpack Compose
  • Base de datos Room para operación sin red y sincronización en Cloud Firestore
  • Lectura de sensores de movimiento y envío automatizado de alertas SMS
Kotlin Jetpack Compose Room Firebase API 24+

Eventify

Aplicación móvil para crear, descubrir y gestionar eventos locales integrando mapas interactivos y servicios en tiempo real en la nube.
